# Confidentialité et éthique

## Cadre
- Loi sénégalaise n° 2008-12 sur la protection des données à caractère personnel ; autorité de contrôle : **CDP** (Commission de protection des données personnelles).
- Les données d'assurance vie (montants, bénéficiaires, situation financière) sont sensibles : elles restent dans le système d'information de NSIA.

## Règles du projet
1. **Consentement** : le client accepte d'être contacté par chaque canal choisi et peut le retirer à tout moment (« STOP » par SMS, bouton dans l'app).
2. **Minimisation** : un message ne contient que ce qui est nécessaire (pas de numéro de police complet dans un SMS, par exemple les 4 derniers chiffres).
3. **Vérification d'identité** avant de donner une information de contrat par chatbot ou vocal (date de naissance ou code reçu par SMS).
4. **Pas de données réelles dans ce dépôt public** ni dans les prompts envoyés à une IA externe : uniquement des données fictives.
5. **L'humain garde la main** : l'IA ne décide jamais d'un échéancier, d'une remise ou d'une résiliation.
6. **Ton respectueux** : aucun message menaçant ou culpabilisant ; aucun contact de tiers.
7. **Traçabilité** : chaque message envoyé est journalisé (date, canal, contenu, résultat).

## Points à valider avec NSIA
- Déclaration du traitement auprès de la CDP.
- Hébergement des données et choix des fournisseurs (SMS, WhatsApp, vocal).
- Relecture juridique et conformité des modèles de messages.
- Relecture des messages en wolof par une personne wolophone.
